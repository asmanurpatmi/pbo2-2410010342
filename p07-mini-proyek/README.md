# Mini Proyek P07 – Katalog Buku Perpustakaan

## Fitur Aplikasi
1. **Menampilkan Data Buku** – Menampilkan daftar buku dalam bentuk tabel.
2. **Tambah Buku** – Menambahkan data buku baru.
3. **Ubah Buku** – Mengubah informasi buku yang sudah tersedia.
4. **Hapus Buku** – Menghapus data buku dengan konfirmasi.
5. **Pencarian Buku** – Mencari buku berdasarkan kode, judul, atau penulis.
6. **Status Buku** – Menampilkan status ketersediaan buku.
7. **Informasi Jumlah Buku** – Menampilkan jumlah buku dan jumlah buku yang tersedia.
8. **Menu Aplikasi** – Menyediakan menu File, Buku, dan Bantuan.
